# Shared inference input/output — 2026-09-14

The canonical CLI now passes a typed `models.io.request.Request` directly to one
runtime. It no longer constructs another model CLI's argv or parses its options
a second time. A resolved MiniWorld `Input` is passed to the feature adapter;
ESMFold2 no longer reloads the original spec after the common MSA limit step.
CCD chemistry, chain order, MSA-LMDB and template-LMDB resolution remain owned by
`data.inference`. Checkpoint feature vocabularies and atom layouts remain explicit
conversion boundaries; they are not interchangeable learned representations.

| Responsibility | Owner |
| --- | --- |
| Input spec, CCD, LMDB resources, MSA limit | `data/inputs`, `models/inference.py` |
| Typed request and legacy flag translation | `models/io/request.py`, `cli.py` |
| Checkpoint binding, compile/graph policy, measured forward loop | `models/io/runtime.py` and existing `models/execution.py` |
| Nonmutating nested feature tensor transfer | `models/io/runtime.py:to_device` |
| Dense AF3 atom layout conversion | `models/io/dense_atoms.py` |
| ESM sequence/LM feature and atom layout conversion | `models/io/sequence_atoms.py` |
| Shared Protenix/OpenDDE flat atom layout conversion | `models/io/flat_atoms.py` |
| Confidence normalization | `models/io/confidence.py` |
| Prediction checks and tensor/CIF/NPZ/JSON persistence | `prediction.py`, `models/io/output.py` |

The model inference modules are legacy API/CLI aliases. They contain no model
forward loop, execution configuration or output writer. Layout adapters yield a
prepared call and decode its result into `Decoded`; the common runtime measures,
validates and saves it. Checkpoint-specific structure decoders retain atom identity,
chain identity, residue numbering and confidence conversion. Protenix/OpenDDE
feature preparation still calls their checkpoint featurizers. This work does not
claim those featurizers or AF3/ESM vocabularies can be replaced without conversion.

## Corrected behavior

- ESMFold2 consumes the already resolved/limited input, as the other models do.
- Protenix's input dictionary is no longer mutated during transfer to the GPU.
- `benchmark_repeats: 0` means one model forward for every model. ESMFold2 formerly
  forced an extra warm forward. Its legacy `seconds_warm` is now null in this case.
- Reports have the same `model`, `backend`, `precision`, `autocast`, observed
  compile/graph fields, sample CIF list and confidence-unit metadata. ESM's backend
  spelling in reports is now `miniworld`; native BF16 is reported as `bf16`.
- Prediction axes must agree: coordinates are sample/atom/xyz; token confidence
  axes agree with PAE and distogram axes; per-sample scores match sample count.
- Saving rejects non-finite values in every canonical head, incorrect pLDDT units,
  missing samples, invalid target filenames and non-JSON report values.
- Existing prediction/CIF/NPZ filenames and confidence arithmetic are preserved.
  Optional heads remain optional, retaining the checkpoint's existing values.
