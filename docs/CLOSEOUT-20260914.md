## Cache build repair

The old script used removed capture APIs/environment switches and only constructed
ESMFold2. The replacement invokes the same released-model CLI for AF3, Protenix,
OpenDDE and ESMFold2. It preserves native precision/configuration, initializes
capture before the first launch, reuses completed round measurements, and writes
provenance-bearing shards into a private cache. Successful units merge serially.
See [CACHE-BUILD.md](CACHE-BUILD.md) for build and inference commands.

Timeout cleanup reuses the engine's process-tree termination, including compiler
children that create independent sessions. Five builder regression tests pass:
exit-code/log preservation, ordinary/detached descendant termination, and
rejection of PyTorch baseline configurations as engine cache builds.
The initial unoptimized startup run was intentionally interrupted after 390 s;
its partial shard and log remain under `validation/closeout-cache/af3-1ubq`.
The corrected run is distinguished by its `-v2` suffix.
